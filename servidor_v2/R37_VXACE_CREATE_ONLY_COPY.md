# R37 — copia independiente VX Ace sin sustituir el archivo de origen

Incidencia R36: IA_VXACE_REPLACE_ACCESS_DENIED_WIN32_5 en The Last Sovereign 1.2.2. El error demuestra que la publicación del RGSS3A no terminó; no demuestra una incompatibilidad del script Ruby. El juego puede seguir arrancando con el recurso original. Los cuatro RAR aportados no pudieron abrirse en el entorno de análisis (error de acceso del runtime); no se pretende haber inspeccionado sus scripts ni se suben archivos del juego.

Nueva vía explícita: botón CREAR COPIA VX ACE o --copy-vxace --game <Game.exe> (opcional --copy-parent <directorio existente>). Solo para RGSS3A. El usuario confirma que el juego está cerrado y se crea una nueva carpeta Juego-IA-VXACE junto a la seleccionada. Se valida y conserva el origen, se copian recursos/configuración/partidas por flujo, y no se copian sidecars ajenos ni se siguen enlaces/reparse points. Si hay una instalación anterior reconocida, se verifica su recibo y respaldo; nunca se usa un respaldo desconocido. El helper recibe un directorio aislado con el archivo original y los recursos mínimos. Se conserva el respaldo verificado en la copia. La salida reconstruida y verificada se crea con O_EXCL como nuevo Game.rgss3a, sin utilizar el reemplazo atómico de un archivo existente. Game.exe se publica al final y se valida la instalación antes de anunciar éxito. Una carpeta incompleta queda señalada y no se borra recursivamente. No se modifican permisos del origen ni se cierran procesos ajenos.

Regresión: fuente con recibo PREPARED/INSTALLED, rechazo de respaldo modificado y enlaces, conservación de partidas. La prueba Windows mantiene un handle sin FILE_SHARE_DELETE, reproduce el rechazo de la instalación ordinaria, exige copia nueva con OPUS real y recuperación, y verifica que el archivo y el recibo originales siguen idénticos. El resto de la suite sigue siendo obligatorio. No se garantiza que una carpeta sin espacio o permisos permita crear la copia. Tampoco se certifica el juego comercial o su integración específica hasta poder ejecutar una prueba real.
