# Servidor Ren'Py — universal development, classic and modern

Official final-release catalog checked against https://www.renpy.org/release_list.html on 2026-11-27: 188 releases (4: 26; 5: 36; 6: 51; 7: 46; 8: 29). This is a coverage target, not a compatibility certificate.

The original classic adapter is informed by public engine interfaces: Ren'Py 4.8.7 uses a flat script directory and renpy.display.text.Text constructor + set_text; the same presentation route is visible in 6.9 and 6.12. Later versions use renpy.text.text.Text. The program detects module layout in loose resources or known ZIP archives, does not extract or execute archived code, records a declared version when accessible, and chooses a compatible candidate profile. Unknown/ambiguous structures remain blocked. Ren'Py 4 and 5 have separate syntax and library requirements; the new minimal classic client avoids modern Python modules, and uses a local authenticated file bridge. In both profiles translation and memory use the same local neural engine; input values and control tokens are excluded. The classic hook is flat and reversible; no original engine, archive, script or save is overwritten.

Official references: https://github.com/renpy/renpy/tree/4.8.7 ; https://github.com/renpy/renpy/tree/6.9.3c ; https://github.com/renpy/renpy/tree/6.12.2.1531 ; https://www.renpy.org/wiki/renpy/releases/5.6.7 ; https://www.renpy.org/wiki/renpy/releases/6.0.0

The compatibility ledger is the complete releases.txt list and batch tool. Each exact release still needs its own verified official package, launch, native text, menu, choices, notifications, input, save/load/rollback, recovery and OPUS inference. Native 4/5 package formats may vary, particularly executables with embedded or frozen modules and legacy Windows requirements; detection alone is not a promise that a game starts. Some classic interpreters lack threading and can translate foreground only; some older Windows packages cannot launch Unicode paths outside the active ANSI code page. These are explicit remaining gates. Image-only text and custom renderers are not yet covered. Do not publish an EXE as universal until exact evidence is available.

For the 6.99.14 test-only graphics hang, select the SDK's own software renderer and skip only its interactive GPU performance prompt. This is not a change to any player's game, SDK binary, sound or graphics settings.
