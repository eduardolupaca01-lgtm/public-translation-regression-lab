# R40 — extracción automática y copia web jugable

R39 aprobado: integración 46034764453, compilación 46034764410, commit 9c401ee2da924de793e2cd31d8fef5125ea0b239, artefacto 15217730922. Se conserva como respaldo.

El usuario no quiere repetir una extracción externa ni buscar index.html manualmente. El botón WEB selecciona el EXE original, con una segunda opción para index.html existente. R40 implementa un lector independiente del formato PE64 y de las tablas embed.FS del compilador Go, con base en la documentación pública del compilador Go 1.23 y Wails v2. No incluye Disrobe, no ejecuta el original, no lee memoria de otros procesos, no obtiene claves ni intenta sortear sistemas de protección. Verifica la estructura del encabezado, referencias virtuales dentro de secciones inicializadas, registros completos, rutas, límites y comprobaciones de integridad de cada recurso. Lee por bloques de 4 MiB; la extracción usa flujos de disco. Exige un único frontend reconocible con index.html y assets locales, compatible con el perfil R39. Los formatos distintos y ambiguos se rechazan de forma explícita. Solo se admite el perfil PE64 estándar, con hashes compatibles; no se afirma que todo Wails ni todo EXE sea compatible.

La copia se crea junto al Servidor mediante webCloneInstall, con modelos verificados, Jugar-IA.exe, WebView2 y nuevas partidas locales. El EXE original no se copia ni se modifica. El directorio temporal creado por la extracción se elimina tras preparar la copia. Las partidas del navegador o del EXE original no se importan. No se modifican las funciones de MV/MZ/VX Ace/SOLData.

Pruebas: Go compila un PE64 real con embed.FS, sin ejecutar la muestra, valida Unicode, contenido exacto y rechazos por corrupción y rutas inválidas. La aceptación empaquetada conserva el recorrido manual R39 y añade un EXE Go real sin archivos externos de 600 MiB de payloads sintéticos distintos, con más de 200 recursos. Se comprueban hashes de todos los recursos, ausencia de temporales, original intacto, traducción OPUS real en WebView2, guardado, F10, cierre y reapertura. No se incluyen datos comerciales. Las pruebas son sintéticas; la extracción concreta del juego sigue sin certificación hasta probar R40 en el equipo del usuario. Fuentes: https://github.com/golang/go/blob/go1.23.6/src/cmd/compile/internal/staticdata/embed.go y https://v2.wails.io/docs/v2.15.0/howdoesitwork/.
