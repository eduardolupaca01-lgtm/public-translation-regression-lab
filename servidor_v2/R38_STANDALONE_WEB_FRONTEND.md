# R38 — modalidad web autónoma experimental

La prueba de la persona usuaria confirma que un frontend Wails extraído puede iniciar y avanzar desde localhost:8765. El español que aparece en el navegador no constituye evidencia de uso de OPUS. La inspección previa encontró módulos web locales, registros de diálogo en inglés/japonés/chino y guardado localStorage; no se incluye ningún recurso o código del juego en este repositorio.

Primera modalidad explícita: `Servidor.exe --web-folder <carpeta dist> --web-port 8765`. No interpreta ni extrae EXE arbitrarios. Reutiliza exclusivamente el trabajador y los modelos verificados del paquete; no cambia el adaptador MV/MZ, VX Ace o SOLData. Sirve la carpeta en 127.0.0.1, con origen y token por sesión, únicamente index.html y assets admitidos, sin exponer la carpeta IA Traductora. El HTML se adapta solo en la respuesta, nunca en disco. Bloquea navegación de recursos a otros orígenes mediante CSP; no habilita depuración o APIs nativas desconocidas. Quit se limita a detener el servidor propio. El perfil es explícito y experimental, no una garantía para todos los Wails.

El adaptador de DOM traduce texto visible, sin modificar atributos funcionales, inputs, nombres marcados, callbacks ni localStorage. El inventario previo busca registros tipados de tres idiomas con campo de audio, prioriza inglés y usa japonés si falta; para estructuras desconocidas se apoya en texto visible. No hay modelo chino en el paquete. F10 informa el inventario y permite detener la sesión. Se conserva el origen http://127.0.0.1:8765 si se utiliza ese puerto; las partidas del EXE nativo no se migran y las del navegador solo se conservan en el mismo perfil y origen. No ejecutar recursos de procedencia no confiable. Para probar, detener el http.server anterior, seleccionar inglés o japonés en el juego y desactivar la traducción automática del navegador. 

Pruebas: Go prepara modelos sin cambiar los archivos web y rechaza rutas ascendentes; Python prueba el inventario no evaluado, aislamiento, rutas, token y servicio; la aceptación empaquetada utiliza Edge real con una página sintética independiente y OPUS auténtico para comprobar texto en el nodo original, cambio de diálogo, botones, entrada protegida, F10, guardado y recarga, cierre y SQLite persistente. Toda la suite RPG previa sigue siendo obligatoria antes del cifrado. R37 permanece disponible como artefacto previo; la PR sigue borrador. La interfaz gráfica de selección de carpetas y el extractor automático quedan fuera de esta primera fase; no se afirma cobertura integral de la aplicación real hasta probarla con el nuevo paquete.
