The SDK version is a period-representative laboratory choice, not identification of the supplied game's precise version. The actual translator and OPUS are not executed in that native loader test; existing R43 presentation tests continue to run unchanged.
- No new runtime/model/translation cache schema, no R44 distributable or support claim for the submitted title at this stage. Need the actual original package.json and evidence of a supported add-on/localization interface. If the game checks integrity and rejects extra code, do not interfere with its checks.
