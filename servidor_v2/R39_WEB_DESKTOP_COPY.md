# R39 — copia jugable de escritorio

El usuario comprobó R38 en modo web, pero solicita una carpeta de juego con ejecutable propio, sin navegador externo ni comandos. El botón WEB del Servidor solicita index.html de la carpeta dist ya extraída y crea una carpeta Juego-IA-WEB junto al Servidor. Solo copia index.html y assets admitidos, con creación exclusiva, comprobación SHA y marcador de copia incompleta. No modifica ni copia el EXE original ni importa el perfil del navegador.

La copia contiene Jugar-IA.exe (WinForms/.NET Framework 4.8, SDK oficial Microsoft.Web.WebView2 1.0.2903.40), sus dependencias y el mismo worker OPUS. Al abrirlo, inicia el servicio loopback en un puerto persistente, muestra una ventana WebView2 propia con perfil local, sin abrir Chrome/Edge externo. Restringe navegación y recursos a la sesión local; no expone APIs de host, depuración, descargas o permisos. Cierra su propio worker y conserva SQLite y las nuevas partidas. Las partidas antiguas de Chrome/EXE no se migran; el origen fijo conserva las creadas en la copia. Requiere WebView2 Runtime y .NET Framework 4.8. La extracción automática y la compatibilidad con otros servicios nativos Wails quedan pendientes.

CI conserva todas las puertas R38 y prueba el lanzador empaquetado con datos sintéticos, WebView2 real, OPUS, menú, cambio de diálogo, guardado, F10 y reapertura con el mismo perfil. Los flags QA solo permiten acciones fijas de un fixture, sin recibir código o URLs. El producto no incluye archivos del juego comercial. La publicación cifrada exige todas las pruebas. R38 y la rama estable se conservan.
