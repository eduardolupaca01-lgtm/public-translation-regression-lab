# R21 — native CTE Spanish boot and contextual first presentation

R20 remains the base. The field report shows connected OPUS and hundreds of received responses, but English presentation. The actual supplied JS shows the native CTE supports language selection through ConfigManager and locates message/choice catalog entries by list metadata and command occurrence. The R20 catalog index was independently reproduced (45,827 pairs, 317 conflicts); a plain reported message maps successfully after indexing, while a message containing the native short pause was rejected. Therefore R21 does not claim a single confirmed cause for all missed surfaces.

- Select native ES on an English boot only when the exact CTE API and EN/ES JSON profile are present. Wait for the native loader with a 12-second bounded fallback to EN; no direct configuration save and no resetting later user language selections. This is the game's existing locale capability; normal native saves may persist the selected language.
- Read priority plugin/quest catalogs early and the active event's specific catalog on demand, using the native map/common/troop context metadata and original command occurrence. Validate exact source/controls and choice counts. No mutation of original message/choice arrays, no replay of events or execution of conditions by the translator.
- Project at native createTextState before formatting and layout; preserve the native control signature including pauses and colors, and preserve the original on an unsafe pair. Native runtime conversion still resolves custom tags. Guard the nonvisual prototype conversion used by the backlog. Fix the proven malformed objective-label template and the complete formatted quest popup. Keep existing F10 and OPUS fallback.
- A separate local test exercised the actual uploaded native RPG Maker and CTE methods against the private catalogs and event lists: the three reported messages, menu label and full quest notification passed before background inventory. The complete commercial game was not run, and its files, source strings and catalogs are not included in this repository. The native locale loader's GUI and all third-party conditions still require real-game acceptance.
- Public CI adds a newly authored synthetic native-shaped regression, includes prior R20 installed-worker acceptance, and publishes only the encrypted translator package if successful.
