# R32 candidato — correcciones de la primera prueba en juego RGSS3

La prueba aportada por el propietario demuestra que el complemento E de R31 se instala y traduce diálogos en un juego real. Se observaron desbordes horizontales, menús ingleses y falta del distintivo permanente. No se modifica el juego ni se incorpora su código o datos al repositorio.

La revisión F mide caracteres con el bitmap y fuente nativos y utiliza el salto/paginación del mensaje original. El texto desplazable se ajusta sin eliminar controles. Para menús, se interceptan exclusivamente bitmaps de ventanas, con un vocabulario común de etiquetas y cola OPUS local no bloqueante para textos desconocidos; los resultados se dibujan por refresh nativo. Se preservan índices/símbolos y nombres de actores; entradas de nombre/número y archivos de guardado se excluyen. Ventanas personalizadas que no ofrecen refresh pueden mostrar el original hasta su siguiente dibujo. El distintivo superior derecho y el panel F10 son informativos, no un subtítulo. La etiqueta del instalador se actualiza a R32.

Las nuevas regresiones reproducen el ancho y altura de una ventana con margen de rostro, texto largo, controles, paginación, Bitmap.draw_text con Rect, menú estándar, descripción enriquecida, refresco asíncrono, selección, nombre protegido y distintivo/F10. La aceptación completa usa también una frase de menú nueva con OPUS real. Se mantiene la validación previa, cifrado y cierre de ambos procesos. Son fixtures sintéticos; la nueva presentación debe comprobarse en el juego real. La migración sobre una instalación R31 no se habilita: usar una copia limpia y cerrada, conservando la anterior y sus partidas. R30 y el candidato R31 aprobado quedan intactos.
